# 비로그인 조회 정책

메인 피드, 공개 게시글 상세(댓글 포함), 공고 목록·상세는 비로그인으로 조회할 수 있다.
프로필 전체와 프로필 활동·연동 정보, 베스트 리뷰·명예의 전당 전체 조회는 인증이 필요하며 비로그인 요청은 401 JSON 응답을 받는다.
수정·삭제와 본인 전용 API의 기존 소유자·역할 검사는 유지한다.

## 공개 리뷰 미리보기

`GET /api/v1/reviews/highlights`는 공통 우측 영역에서 사용한다.
기존 전체 조회 API를 재사용하면 비로그인 사용자가 전체 내용을 직접 조회할 수 있으므로 공개 요약 응답을 분리한다.

- `reviews`: 최신 주간 베스트 리뷰 최대 3개. username, nickname, content, rank, likeCount.
- `reviewers`: 명예의 전당 상위 최대 3명. rank, username, nickname, reviewCount, selectionCount, representativeContent.
- 본문은 최대 100 유니코드 코드 포인트와 생략 표시로 제한한다.
- 기간 선택·페이지 탐색은 제공하지 않는다. 로그인 여부와 무관하게 동일한 요약만 반환한다.
- 기존 `/reviews/best`, `/reviews/hall-of-fame`은 로그인 후 사용한다.

프로필 라우트는 서버에서 인증 없이 프로필을 미리 조회하지 않는다. 로그인 확인 후 브라우저가 세션을 포함해 기존 프로필 API를 조회한다. 메타데이터는 일반 제목과 noindex를 사용한다.

공개 이미지 경로의 사진 접근 권한은 이 변경 범위에 포함하지 않는다. 비공개 이력서 원본 사진의 권한 보호는 별도 작업이 필요하다.
